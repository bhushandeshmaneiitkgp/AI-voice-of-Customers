# Root-Cause Hypotheses

**2026-09-02** · 10 pain points examined · 30 grounded hypotheses · model `meta-llama/llama-3.3-70b-instruct`

Phase 4 ranked what hurts and Phase 5 showed where it is worse. This asks *why*, using only the reviews the retriever supplied for each pain point.

---

## These are hypotheses, not findings

Every item below is a **candidate mechanism** generated by a language model from customer text. Customer reviews describe symptoms; they cannot establish causes. That is why each hypothesis carries a **proposed check** — the observation that would confirm or kill it. The check is the actionable output; the hypothesis is a reason to run it.

**Every citation is verified.** A hypothesis may only cite review ids that were actually supplied to the model for that pain point. One citing anything else is rejected outright rather than repaired — stripping the bad id would leave a claim whose stated support does not exist, which reads as evidence-backed and is not.

## Caveats

**A verified citation is not a verified cause.** The check confirms the model quoted reviews it was given. It says nothing about whether the mechanism is real.

**Confidence is self-reported.** Phase 9's gold set is what would turn these into measured claims.

**Retrieval is semantic and bounded.** Each pain point saw at most the reviews the index ranked closest to it. A cause visible only in reviews outside that set cannot be proposed.

**0 of 10 pain points produced nothing.** Where that happened it is reported above rather than omitted.
